# Week 4: JavaScript Fundamentals

## What I Built
- **Calculator**: A multi-operator calculator supporting `+`, `-`, `*`, `/`, `%`, and `**`, with built-in safeguards against division and modulo by zero.
- **Student Grade Tracker**: An array-and-object management script utilizing array methods (`reduce`, `filter`, `find`) to calculate student and class averages.
- **Daily Challenges**: Implemented algorithmic solutions for FizzBuzz, string reversal, largest number finding, duplicate removal, and palindrome checking.

## Lessons Learned
- **Strict Equality (`===`)**: Learned why strict equality prevents unexpected type coercion bugs (e.g., stopping string `"5"` from evaluating equal to number `5`).
- **Scope Safety (`const` and `let`)**: Enforced block scoping and prevented variable mutation errors by completely avoiding `var`.
- **Array Iteration Methods**: Practiced functional array transformations using `.reduce()` for accumulating sums and `.filter()` for data subset extraction.
